初识 WSL2：以 Ubuntu 24.04 安装为例

发表于 2025-10-08 更新于 2025-11-29
分类于 Linux Valine：
近期需要在 Windows 上搭建一套 Linux 开发环境，本文记录了通过 WSL2 安装 Ubuntu 24.04 的完整过程。

0 前言

笔者早期使用的是 Windows / Ubuntu 双系统，但系统切换过于不便，对于有着日常 Windows 办公需求的开发者来说并不友好；后来转投 VMWare 虚拟机，整体体验尚可，但虚拟机很吃系统资源且无法使用主机的 GPU。

WSL（Windows Subsystem for Linux）是微软开源的一套用于在 Windows 中直接运行 Linux 环境的轻量虚拟化解决方案，弥补了双系统使用不便和虚拟机资源开销大的缺点，并且能够直接访问主机的 GPU。WSL 目前已发展到 WSL2，对比 WSL1 的主要区别如下：
